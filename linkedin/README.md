# Projeto LinkedIn: Pedro R Gomes · PK7

**Objetivo:** o LinkedIn passa a contar a mesma história do site pk7.com.br, com o mesmo nome, a mesma foto, os mesmos números e os mesmos links, e ganha conteúdo toda semana. A ideia é virar autoridade para quem pesquisa "Pedro R Gomes PK7", para o Google e para as IAs.

## Arquivos

| Arquivo | Para quê |
|---|---|
| `PERFIL_PRONTO.md` | Os textos do perfil, campo por campo: nome, título, sobre, experiência, competências, destaques, serviços e versão em inglês |
| `PROMPT_CLAUDE_CHROME_LINKEDIN.md` | Prompt para o Claude for Chrome aplicar o perfil enquanto você supervisiona. Ele gera `EXECUCAO_LINKEDIN_PK7.md` |
| `banner_linkedin_1584x396.png` | A imagem de capa, no tamanho oficial |
| `carrossel_nao_contrate_a_pk7.pdf` | Carrossel de 8 páginas (post 2), para anexar como documento |
| `POSTS_4_SEMANAS.md` | 12 posts prontos (3 por semana), rotina diária de 20 min, modelos de convite e de resposta |
| `fonte/` | O HTML do banner e do carrossel, a foto e a placa, para editar depois |

## Ordem

1. **Hoje:** rode o prompt no Claude for Chrome e acompanhe. Responda o que ele perguntar (datas e cargos). Quando ele pedir, faça os uploads: banner, foto e vídeo.
2. **Hoje:** me mande o `EXECUCAO_LINKEDIN_PK7.md` que ele gerar. Eu reviso.
3. **Terça:** post 1. Depois siga o calendário de `POSTS_4_SEMANAS.md`.
4. **Todo dia:** 20 minutos de comentários, respostas e convites.
5. **Depois de 4 semanas:** me mande os números de cada post (impressões, comentários, visitas ao perfil). Eu monto as 4 semanas seguintes dobrando o que funcionou.
